# MenuPizzeria
Sito web per una pizzeria grande piramide d'egittocreando appunto il menu: pizze, primi, secondi, dolci, bevande
Ogni sviluppatore deve aggiungere due portate nel proprio menù:
-Sviluppatore A: Pizze
-Sviluppatore B: Primi
-Sviluppatore C: Secondi
-Sviluppatore D: Dolci
-Sviluppatore E: Bevande
